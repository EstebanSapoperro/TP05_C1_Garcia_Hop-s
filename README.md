# Infinite Side Runner

Un **infinite side runner** desarrollado en Unity, en el que el jugador debe avanzar lo máximo posible mientras supera los obstáculos que aparecen en el camino.

## Controles

| Tecla        | Acción                      |
| ------------ | --------------------------- |
| `W`          | Saltar                      |
| Mantener `W` | Realizar un salto más largo |
| `S`          | Bajar rápidamente           |

## Características

* Gameplay de tipo **Infinite Side Runner**.
* Sistema de salto con altura variable.
* Posibilidad de descender rápidamente.
* Partidas centradas en conseguir la mayor puntuacion posible.
